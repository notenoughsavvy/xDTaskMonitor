# Task Tracker & Planner Web App

A modern, responsive Task Tracker web application built with HTML5, Tailwind CSS, and vanilla JavaScript. Features dynamic calendar date selection, task management (CRUD), interactive progress tracking, local user authentication, and simulated email & browser reminders.

## Features
- **Interactive Monthly Calendar:** Select dates to view, add, or manage scheduled tasks.
- **Task Management:** Create, view, complete, and delete tasks with custom priorities, times, and reminder schedules.
- **Progress Tracking Analytics:** Live updates for assigned, completed, and progress completion percentages.
- **Email & Browser Reminders:** Automated engine checking due dates and triggering notifications.
- **User Authentication:** Guest mode or user account persistence stored via `localStorage`.

## Quick Start
1. Clone this repository or download the files.
2. Open `index.html` directly in any web browser.
